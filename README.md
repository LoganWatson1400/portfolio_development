# Logan Watson Portfolio

Welcome to my personal portfolio website. This project showcases my experience, technical projects, and contact information through an interactive terminal-inspired interface.

## Features

* Terminal-style navigation system
* Continuous scroll browsing option
* Responsive design
* Lightweight and interactive UI

## Overview

This portfolio was built to blend a traditional portfolio website with a developer-focused terminal experience. Visitors can either navigate using terminal-style commands or browse normally through continuous scrolling.

The site highlights my background, software projects, and technical skills while providing a unique and intuitive user experience.

## Tech Stack

* Svelte
* JavaScript
* GitHub Pages
